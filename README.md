# Earth-Moon Sim — Phase 1 (Cube-Sphere Quadtree LOD)

地球〜月シームレス・フライトシミュレータの Phase 1：単色の地球サイズの球を、
宇宙から地表すれすれ（数m）までシームレスに表示する LOD 骨格。

## 実行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

操作：クリックでマウス視点 / WASD 移動 / Q E 上下（惑星の真上方向） / Shift 加速 /
1-5 速度倍率 / G ワイヤー / R 自動水平化切替 / Esc マウス解放。
速度は高度に自動適応する（宇宙では km/s 級、地表では m/s 級）。

視点はクォータニオン1本で管理し、回転は常に**自分の視点基準**で適用する
（左右＝自分の頭上軸、上下＝自分の右軸）。オイラー角方式と違い、真下・真上を
向いた状態でもジンバル的に退化せず、天頂を通ってその先まで視点を回せる。
視点基準回転の副作用（地平線に対するロールの蓄積）は、局所天頂方向への
スラーで自動水平化する（Rで切替、天頂±13°以内は縮退回避でスキップ）。

## アーキテクチャ

| ファイル | 役割 |
|---|---|
| `src/tileGeometry.ts` | Cube-Sphere タイル生成。tan 写像で 6 面を球に写像。頂点は「タイル中心(double)＋ローカルオフセット(float)」で生成（Phase 2 の精度レイアウトを最初から適用）。外周 1 頂点分のスカート付き |
| `src/tileMesh.ts` | タイル描画オブジェクト。メッシュ原点＝タイル中心（double） |
| `src/cubeSphereLod.ts` | 四分木 LOD。スクリーン空間誤差 ρ = 矢高/距離×pxPerUnit で分割(>2px)/統合(<0.2px)。子 4 枚の生成完了まで親を表示（穴なし）。LRU ジオメトリキャッシュ、フラスタムカリング、構築キュー（フレーム予算） |
| `src/materials.ts` | 自前シェーダ（単色＋ランバート＋ワイヤ表示）。logarithmicDepthBuffer 対応 |
| `src/cameraRig.ts` | フリーフライトカメラ。高度適応速度・near 面調整 |
| `src/testAuto.ts` / `src/main.ts` | 自動検証用オートパイロットとピクセルプローブ |

単位はメートル、原点は地球中心、半径 6,371,000 m。JS の number は float64 なので
CPU 側はすべて double で保持し、GPU にはカメラ相対の小さな float 値だけが渡る。

## テストモード（URL パラメータ）

- `?demo=hover&alt=200000` 高度 200 km に固定
- `?demo=drop` 25,000 km → 100 m まで自動降下（`&wire=1` でワイヤ、`&speedup=N` で高速化）
- `?demo=bounce` 降下↔上昇を反復（統合・キャッシュ・チャタリング耐性の検証）
- `?demo=look` 視点回転テスト：真下向きから水平→90°旋回→天頂通過→復帰（クォータニオン視点の検証）
- `&probe=g` 6×6 グリッドのピクセルを読み、異常（空色・異常暗色＝クラック）を数える

## 検証結果（2026-09-23）

- 宇宙(25,000km)→地表(2m) までの全自動降下：60fps、クラック検出 0、シェーダエラー 0
- LOD 深度は高度から導かれる理論値と一致（100m→L12、600m→L11、20km→L8、200km→L7、10,000km→L4、2m→L15）
- バウンス 73 サイクル：ジオメトリ再構築は初回 2,638 で以後増加ゼロ（LRU キャッシュ命中率ほぼ 100%）、統合↔分割のチャタリングなし
- 定常状態のアクティブタイル ≈550 枚（最大 3,000 万三角ポリゴン）、ドローコール ≈540
