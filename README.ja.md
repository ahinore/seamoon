# SEAMOON(シームーン)

**地球の海岸から月の地表まで、ひとつながりのフライトで。実際のスケールのまま。**

[English README](README.md)

Seamoon は「地球〜月系全体を、継ぎ目のないひとつの空間として飛べる」という
コンセプトの WebGL 宇宙飛行シミュレーターです。太陽の照らす砂浜から出発し、
雲を抜けて上昇しながら地球全体を振り返り、384,000 km の宇宙空間を横断して、
月のクレーターの地表に着陸するまで —— ローディング画面もシーン切替も
テレポートも一切ありません。カメラは最後まで同じ世界の外に出ません。

## 概要

- **実スケールの地球月系。** 地球半径 6,371 km・月半径 1,737 km・実際の
  軌道距離 384,400 km。砂の上 2 m から 40 万 km の彼方まで、ひとつの座標系
  の中を飛びます。
- **ガイド ツアーを一本収録。** `?demo=tour` で全編自動飛行: 海岸で 3 秒の
  カウントダウン → 雲の高さまで後ろにドリフトしながらゆっくり上昇 → 地球
  全体+月上端の構図へなだらかにパン → 月を回り込んで → 地球の見える月面へ
  着陸(所要約 2 分半)。
- **いつでも自由飛行に。** ツアー中に F キーでカメラを奪取、または最初から
  フリーモードで自機を操縦。地表付近は飛行機モード、宇宙はニュートン力学
  による軌道飛行、月面はランダーです。
- **全要素プロシージャル生成。** 地形・クレーター・雲・海・星はすべて
  ノイズ関数から実行時に生成。テクスチャのダウンロードはありません。

Seamoon は**ローカル LLM によるソフトウェア開発の実証テスト**として
開発されました。コード全体を **GLM-5.3-Flash** のみで記述・デバッグし、
**NVIDIA DGX Spark 2 台**のローカル環境でおよそ **1 週間**自立動作させて
開発を進めました。人間は進行を見守り、適宜バグ報告や修正のコメントを
返しただけで、実装・テスト・修正はすべてローカル モデルが行いました。

## セットアップ

必要なもの: **Node.js 18+** と WebGL2 対応ブラウザ(Chrome/Edge 推奨)。

```bash
git clone https://github.com/ahinore/seamoon.git
cd seamoon
npm install
npm run dev
```

**http://localhost:5173** を開き、キャンバスをクリックしてマウス視点を
取得してください。

本番ビルド:

```bash
npm run build     # dist/ に出力
npm run preview   # ビルドをローカルで確認
```

開発に GPU は不要で、WebGL2 が動く環境であれば実行できます。レンダラーは
2 m〜200 万 km の深度範囲を扱うため反転 float 深度バッファを使用しています。

## 操作方法

**フリー飛行(既定モード)**

| キー | 動作 |
|---|---|
| クリック | マウス視点の取得/解放 |
| `W` `A` `S` `D` | 移動 |
| `Q` / `E` | 下降/上昇(惑星の真上方向基準) |
| `Shift` | 加速 |
| `1`–`5` | 速度倍率 |
| `G` | ワイヤーフレーム表示 |
| `H` | 初期位置へ戻る |
| `R` | 自動水平化の切替(地平線を安定化) |
| `Esc` | マウス解放 |

速度は高度に自動適応します(地表では m/s 級、宇宙では km/s 級)。

**飛行機モード(`F`)** — 惑星の地表付近では機体モデルに切り替わります:
マウス/矢印キーが操縦桿、`W`/`S` がスロットル、`A`/`D` がラダー。
もう一度 `F` でフリー飛行に戻ります。

**ガイド ツアー(`?demo=tour`)** — 地球→月の全編(約 2 分半)を自動飛行。
停止点で `F` を押すとその場から自由操縦に移行します。

**月着陸デモ(`?demo=lunar`)** — ランダーを操縦: `W`/`S` スロットル、
`A`/`D` ラダー、マウス/矢印で機体を傾けます。HUD の `AGL 0 m` で軟着陸。

## デモモード(URL パラメータ)

| URL | 内容 |
|---|---|
| (なし) | 海岸からスタートするフリー飛行 |
| `?demo=tour` | 地球→月のガイド ツアー全編 |
| `?demo=hover&alt=200000` | 指定高度(m)でホバー |
| `?demo=drop` | 25,000 km → 100 m への自動降下(LOD 耐性テスト) |
| `?demo=look` | 天頂を通る視点回転ストレステスト |
| `?demo=orbital` | 地球周回のニュートン軌道飛行(`&moonshot=1` で TLI→着陸までのミッション) |
| `?demo=lunar` | 月ランダー |
| `?lat=..&lon=..&alt=..` | スポーン位置の指定 |

## プログラムの作り

Seamoon が解いている核心は「**6,371 km の惑星と 2 m の岩石を、同じカメラ
でクリッピングもジッターもなしに描画する**」ことです。構成要素:

**倍精度フローティング オリジン。** 全座標は JavaScript の float64 による
絶対メートル値(地球中心基準)。毎フレーム、原点をカメラ位置へ再センタリング
し(`src/world.ts`)、GPU には小さな float32 のカメラ相対値だけが渡るため、
どのスケールでも頂点ジッターが発生しません。

**キューブスフィア四分木 LOD(`src/cubeSphereLod.ts`)。** 各天体は立方体を
球面へ投影した 6 面で構成され、スクリーン空間誤差(ρ > 2 px で分割、
< 0.2 px で統合)でレベル 15(約 2 m タイル)まで分割されます。タイルは
亀裂隠しのスカート付き。LRU ジオメトリ キャッシュで再構築をほぼゼロに抑え、
フレーム予算付き構築キューと Web Worker(`src/tileWorker.ts`)がメイン
スレッドからタイル生成を分離します。

**すべて自前シェーダー(`src/materials.ts`、`src/clouds.ts`、
`src/seaGeometry.ts`、`src/atmosphere.ts`、`src/moonMaterial.ts`)。** 大気、
雲層(レイマーチングによる影パス付き)、アニメーションする海洋、地形照明、
月面はすべて反転 float 深度に合わせた手書き GLSL です。植生
(`src/scatter.ts`、`src/vegMaterial.ts`)はタイル単位の GPU インスタンス。

**ひとつの物理サンドボックス(`src/flight.ts`、`src/orbit.ts`、
`src/moonOrbit.ts`)。** 地表付近はアーケード的な航空機モデル、宇宙では
同じ機体がケプラー軌道力学(円錐曲線接続)に従います。TLI→月遷移→捕捉→
着陸までのミッションも収録。月は実際の 384,400 km・軌道傾斜角 5.14° の
パスを公転し、両天体はひとつの絶対フレーム レジストリ
(`src/frames.ts`)を共有します。

**クォータニオン専用カメラ(`src/cameraRig.ts`)。** 回転はすべて視点空間で
適用する 1 本のクォータニオンで管理され、ジンバル ロックなしで天頂を
通って視点を回せます。自動水平化アシストはロールを局所地平線へ緩やかに
戻します。

**自己検証するオートパイロット(`src/testAuto.ts`)。** ガイド ツアーと
デモ モードはテスト ハーネスを兼ねたオートパイロットが駆動し、HUD に状態を
出力、ピクセル プローブ用の URL フックと組み合わせて回帰検証を行えます
(1 週間の自立開発でもこの仕組みで自己テストされました)。

| モジュール | 役割 |
|---|---|
| `src/main.ts` | 起動・フレーム ループ・HUD・ナビ マップ・天体矢印 |
| `src/world.ts` | フローティング オリジン/再センタリング |
| `src/frames.ts` | 天体フレーム、lat/lon ↔ 絶対座標 |
| `src/cubeSphereLod.ts` | 四分木 LOD の中核 |
| `src/tile*.ts` | タイル ジオメトリ・メッシュ プール・Web Worker |
| `src/terrain.ts` / `src/noise.ts` | 地球のプロシージャル地形 |
| `src/moon*.ts` | 月のプロシージャル生成(クレーター・マテリアル・公転) |
| `src/clouds.ts` / `src/seaGeometry.ts` / `src/atmosphere.ts` | 気象・海洋・大気 |
| `src/scatter.ts` / `src/vegMaterial.ts` | 植生インスタンス |
| `src/cameraRig.ts` | カメラ・自動水平化 |
| `src/flight.ts` / `src/orbit.ts` | 飛行モデルとケプラー軌道力学 |
| `src/testAuto.ts` | オートパイロット・ツアー・プローブ |
| `src/hud.ts` / `src/audio.ts` | HUD とサウンド |
